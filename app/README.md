# 绯夜对决 · Velvet Fight

原创 3D 美少女 2.5D 格斗游戏。尹世琳与姜艺娜在雨夜首尔高空会所天台展开一对一、三局两胜的对决。

## 运行

```bash
npm install
npm run dev
```

生产构建：`npm run build`，预览构建：`npm run preview`。

## 操作

| 功能 | 玩家 1 | 玩家 2 |
|---|---|---|
| 移动 / 跳跃 / 蹲伏 | W A S D | 方向键 |
| 轻攻击 | J | 小键盘 1 |
| 重攻击 | K | 小键盘 2 |
| 特殊技 | L | 小键盘 3 |
| 投技 | U | 小键盘 4 |
| 超必杀（满能量） | I | 小键盘 5 |
| 冲刺 | 快速双击 A / D | 快速双击左右方向键 |

- 后拉防御；投技不可防御。
- 特殊技配合上方向为对空技，配合左右或下方向为突进技。
- 轻攻击命中后可取消接重攻击或特殊技；连段伤害会递减。
- 空格快速开始 / 确认，Esc 暂停，M 静音。

## 内容

- 两名独立角色：长距离踢技与近身突进两种打法。
- 单人对 AI（简单 / 标准 / 困难）与本地双人。
- 60 秒回合、三局两胜、选人、暂停、胜负结算与再战。
- 轻重攻击、空中攻击、蹲伏、防御、投技、浮空、连段取消、能量与超必杀。
- 高精纹理 GLB 角色、程序化整体姿态动作、雨夜天台、城市灯光、命中特效与合成音效。
- 高画质 / 流畅设置与自动降级。

## 技术

Three.js + TypeScript + React 外壳；60 Hz 固定步长战斗逻辑；实例化城市与粒子；高精 GLB 角色加载与程序化姿态动画；Web Audio 合成音乐与音效。全部运行资源在本地，无在线服务依赖。

角色以首界面立绘为参考生成高精 3D 模型，当前动作采用整体姿态驱动，并非完整骨骼动画；加载失败时回退到程序化关节模型。首版不含网络对战、故事模式、换装或在线排行榜。
